# 吞吞大乱斗

一款原创的"吞噬成长"类网页小游戏：吃掉比你小的，躲开比你大的，长成全场最大的那一个。

**在线试玩：https://fuzzylogic112.github.io/blob-brawl/**

纯前端单页（HTML5 Canvas + 原生 JavaScript），不依赖任何外部资源，打开网页就能玩，电脑和手机都支持。

## 玩法

- 移动吃掉地图上的彩色豆子，慢慢变大
- 质量比对方大 25% 才能吃掉对方；个头越大，移动越慢
- **分身**：把自己一分为二，小球向前冲刺，用来突袭或逃命；一段时间后自动合体
- **吐球**：吐出一小块质量，可以喂队友、诱敌，或者喂刺球
- **刺球**（绿色锯齿球）：小球可以躲在下面；大球撞上会被炸成很多碎块；往刺球里吐 7 次球，它会分裂并朝吐球方向射出一个新刺球
- 大于一定质量后会缓慢流失，排行榜会一直变化

## 操作

| 平台 | 移动 | 分身 | 吐球 | 暂停 |
| --- | --- | --- | --- | --- |
| 电脑 | 鼠标 | 空格 | 按住 W | Esc / P |
| 手机 | 左手按住屏幕拖动（浮动摇杆） | 右下角「分身」 | 按住「吐球」 | 顶部暂停键 |

## 模式

- **经典模式**：无限成长，被吃掉就结束，记录最高质量
- **限时对战**：3 分钟内尽量长大，被吃可立即复活，时间到按质量排名

## 其他特性

- 26 个 AI 对手，会吃豆、追杀、逃跑、分身突袭、绕开刺球
- 16 款程序绘制的原创皮肤（纯色 + 西瓜、星空、甜甜圈、篮球、地球、熊猫、彩虹糖）
- 实时排行榜、小地图、击杀提示、音效（可关闭）
- 最高纪录保存在本地浏览器

## 本地运行

直接双击打开 `index.html` 即可，或者：

```bash
npx serve .
```
